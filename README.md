# 多姿态步态加速度特征采集与对比

本仓库整理五种日常状态的手机三轴加速度采样数据，并提供统计结果、波形图和初步动作区分规则。

## 测评内容

| 状态 | 采样时长 | 采样频率 |
| --- | ---: | ---: |
| 静止 | 30 秒 | 约 404 Hz |
| 平地慢走 | 30 秒 | 约 404 Hz |
| 上楼 | 30 秒 | 约 404 Hz |
| 下楼 | 30 秒 | 约 404 Hz |
| 平地快跑 | 30 秒 | 约 404 Hz |

## 数据与方法说明

原始 CSV 保留时间戳、X/Y/Z 轴加速度及绝对加速度列。为使每段记录时长精确为 30 秒，末尾增加一条线性插值边界记录，其余采样点保持不变。

分类阈值基于当前每种状态各一段样本，仅作初步筛查。慢走、上楼和下楼的特征存在重叠，结果不应视为经过独立样本验证的通用分类器；详细限制和计算方法见[测评说明](实地测评/README.md)。
