# 数据说明

> ICEC-2026-0139 · 课题 06 校园昼夜声学噪声地图测绘

## 1. 数据来源

全部数据由手机分贝计 **Decibel X**（iPhone 内置麦克风，A 计权）在校园现场实测导出，
未经人工修改或填补。原始文件为 App 导出的文本记录，包含摘要头（Min / Max / Peak / Avg）与
时间序列（1 s 等效声级 + 毫秒时间戳）。

| 项 | 说明 |
| --- | --- |
| 采集期 | 2026-11-02 – 2026-11-11 |
| 点位 | 图书馆、食堂、主干道、操场、实训室走廊 |
| 时段 | 早 07:00–10:30 / 午 11:30–15:40 / 晚 18:30–21:10 |
| 单次窗口 | 20.6 – 28.1 s |
| 采样间隔 | 约 200 ms（5 Hz） |
| 有效记录 | 15 份（5 点位 × 早 / 午 / 晚） |
| 1 s 样本总数 | 1 625 条 |

## 2. 归档结构

```
data/raw/
├── 早/
│   ├── 图书馆.txt    ├── 食堂.txt      ├── 主干道.txt
│   └── 操场.txt      └── 实训室.txt
├── 中/ …（同上 5 个点位）
└── 晚/ …（同上 5 个点位）
```

**目录即元数据**：`<时段>/<点位>.txt`。分析脚本不解析文件名，也不依赖 App 的导出命名，
因此补测数据只要放对目录就能被自动识别。补测压缩包可用 `analysis/ingest.py` 一键归一化。

## 3. 字段定义

原始文件头部 4 个摘要字段与正文时间序列的关系：

| 原始字段 | 含义 | 本报告用法 |
| --- | --- | --- |
| `Min (dB-A)` | 窗口内最小瞬时值 | 不直接使用，另取样本最小值为 `Lmin` |
| `Max (dB-A)` | 窗口内最大瞬时值 | 不直接使用，另取样本最大值为 `Lmax` |
| `Peak (dB-A)` | 峰值保持（线性峰值，不做时间计权） | 直接作为 `Peak` |
| `Avg (dB-A)` | 窗口平均值 | 直接作为 `L_Aeq`，并与样本能量平均交叉校验 |
| 正文 `Leq, 时间戳` | 每约 200 ms 一个 1 s 等效声级 | 用于统计声级、标准差、光效仿真回放 |

> 说明：App 的 `Avg` 与正文序列的能量平均存在 ±0.1 dB 的舍入差异，属导出精度问题，不影响结论。

## 4. 计算口径

- **能量平均**：`Leq = 10·lg(Σ10^(Li/10) / n)`，禁止算术平均。
- **统计声级**：样本升序排列后按分位取，`L10` 表示 90% 的时间声级高于该值。
- **标准差**：总体标准差（`pstdev`），反映窗口内声级起伏，非时段间波动。
- **超标判定**：`Leq > 限值` 即为超标；等于限值时判为达标（G07 70.0 dB、G11 55.0 dB 均属此类边界工况）。
- **昼 / 夜**：早、午按昼间限值；晚按夜间限值。夜间限值切换是图书馆（50→45）、
  操场（55→45）由达标转超标的主要原因。

## 5. 误差来源与局限

| 来源 | 影响 | 应对 |
| --- | --- | --- |
| 手机麦克风未做声校准 | 绝对声级存在 ±2 dB 量级系统偏差 | 强调同机型、同位置的横向可比性 |
| 单次窗口仅 20–28 s | 不能代表完整时段等效声级 | 定位为「瞬时声环境画像」，非合规性评价 |
| 手持测量存在人体反射与遮挡 | 低频段可能偏高 1–3 dB | 统一持握高度与朝向 |
| 每点位每时段仅 1 次采样 | 无法做时段间重复性检验 | 后续建议每时段 3 次取能量平均 |
| 天气与人群随机性 | 雨天、考试周等会显著改变结果 | 记录采集日期，便于复核 |
| **扩声系统（实测已发生）** | 闭馆音乐等稳态声源叠加进背景，读数不代表该空间本底 | 见 §5.1，G03 已标注为含音乐组 |
| **风噪（实测已发生）** | 风直吹麦克风产生湍流伪声，A 计权读数偏高 6–10 dB，且以低频为主 | 见 §5.2，G09 已标注为受污染组 |

### 5.1 闭馆音乐个案：G03 图书馆晚间

现场记录：测量时图书馆已响起闭馆音乐，馆内扩声系统持续播放。该组读数 60.7 dB 为「闭馆音乐 + 馆内背景」
的叠加值，比 1 类区夜间限值 45 dB 高 15.7 dB。

窗口统计形态与「稳态声源」高度一致，与偶发人流噪声不同：

| 指标 | G03 图书馆晚间 | 对照 |
| --- | --: | --- |
| σ（样本标准差） | **1.40** | 食堂午间 3.00（人流 + 餐具） |
| L10 − L90 | **3.7** | 操场早间 13.1（跑操间歇） |
| Peak − Leq | **4.7** | 食堂午间 24.6（餐具碰撞瞬态） |

连续播放的扩声系统能量平稳、缺少瞬态尖峰，因此 σ 与峰均差都很小。这同时意味着在时域上**无法把音乐
与背景声分离**——两者在时间上完全重叠、在频段上亦有重叠，单次录音无法拆分各自贡献。

**结论**：G03 是「闭馆音乐播放期间馆内人员的真实暴露声级」，用于评价「闭馆时段实际感受」是有效的；
但**不能用于评价图书馆夜间声环境本底是否达标**，`+15.7 dB` 也不应解读为阅览区噪声失控。

**改进措施**：闭馆音乐按背景音乐管理，音量控制在 55 dB(A) 以内，或改为闭馆前 15 min 短时播放；
评价夜间本底时，应在音乐停止后 5–10 min 取样。

### 5.2 风噪污染个案：G09 主干道晚间

现场记录：G09 测量期间有风，点位位于校园主干道，四周开阔无遮挡，手机直接暴露在气流中。
风噪不是「环境里真的更吵」，而是气流冲击传声器振膜产生的**湍流伪声（pseudo-noise）**，
其能量集中在低频，经 A 计权后仍有可观残留，会整体抬高读数。

三组主干道数据构成内部对照，可量化这一污染：

| 组 | 时段 | Leq | Peak | σ | L10−L90 |
| :--: | :--: | --: | --: | --: | --: |
| G07 | 早 | 70.0 | 85.8 | 3.02 | 6.9 |
| G08 | 午 | 69.5 | 81.6 | 2.60 | 6.3 |
| G09 | 晚 | 67.1 | 85.0 | **4.50** | **10.7** |

- **昼夜落差仅 2.7 dB**。城市交通干线夜间车流量通常降至昼间的 10–20%，对应 Leq 回落 8–12 dB。
  2.7 dB 的落差在物理上不合理，缺口即风噪抬升量。
- **σ 由 2.6–3.0 升至 4.5**。稳态交通流的窗口内起伏小；阵风是突发性、间歇性的，会把 σ 推高。
- **L10−L90 由 6 dB 扩大到 10.7 dB**。说明少数高值片段（阵风峰值）显著拉高了能量平均——
  这正是 L90 只有 58.9 dB 而 Leq 达 67.1 dB 的原因。
- **Peak 85.0 dB 高于午间 81.6 dB**。夜间车流更少、大型车比例更低，峰值本应更低；
  反超说明有非交通类瞬时冲击叠加。

**结论**：G09 的 67.1 dB 应视为**含风噪的上限值**。扣除 6–10 dB 抬升后，真实夜间 Leq 约 57–61 dB(A)，
仍高于 4a 类区夜间 55 dB 限值，**超标判定不变**，但具体超标量（+12.1 dB）不应引用。

**改进措施**：加装防风罩（foam windscreen，可降风噪 10–15 dB）；风速 > 3 m/s 时暂停记录；
夜间测量延长至 10 min 以覆盖完整车流周期。

## 6. 与其他标准的关系

限值取自 **GB 3096-2008《声环境质量标准》** 与 **GB 50118-2010《民用建筑隔声设计规范》** 的
允许噪声级，用于判定参考。需注意：

- GB 50118 的「允许噪声级」衡量的是建筑空间的背景噪声设计目标，而非使用工况下的人群活动声；
  食堂就餐高峰的实测值（71.9–78.1 dB）含大量人群交谈声，按该口径判定偏严格。
- 校园内部尚未划定正式声环境功能区，本报告按「点位功能最接近的类别」赋值，属工程近似。
- 15 组数据的核心价值在于**点位之间、时段之间的相对比较**，以及作为光效阈值的标定依据。
- G09 受风噪污染，参与横向比较时应按「上限」理解，不宜与其他组做等精度对比。
- G03 含闭馆音乐，反映的是「有音乐时的暴露」而非本底；与其他组比较时须注意口径不同。
